# iSimora

> An experimental iOS emulator focused on bringing iOS 16 and earlier to virtualized environments.

iSimora is an experimental project exploring the emulation of Apple mobile devices and their software environments. Its goal is to make running and experimenting with older iOS versions possible in a virtualized environment.

## Overview

iSimora aims to provide an emulated iOS environment with support for older iOS releases, targeting iOS 16 and below.

The project focuses on researching and implementing the hardware, operating system, and system-level components required to bring an iOS environment to life.

## Project Goals

- [ ] ARM64 CPU emulation
- [ ] Virtual Apple device hardware
- [ ] iOS boot support
- [ ] XNU kernel compatibility
- [ ] iOS userspace support
- [ ] Virtual storage and filesystem
- [ ] Display and touch input
- [ ] Networking support
- [ ] Audio support
- [ ] SpringBoard integration
- [ ] Application execution

## Supported Versions

iSimora is targeting iOS 16 and earlier.

Compatibility will depend on the device generation, firmware version, and implemented emulation features.

| iOS Version | Status |
|---|---|
| iOS 16 | Experimental |
| iOS 15 | Planned |
| iOS 14 | Planned |
| iOS 13 | Planned |
| iOS 12 and earlier | Planned |

*Compatibility statuses are subject to change as development progresses.*
